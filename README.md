# 定期預金 利息ダッシュボード

## できること
- 複数の定期預金を登録
- 今日の合計利息を税引前・税引後で表示
- 今月の累計利息を表示
- 満期までの予定利息を表示
- 今後30日の日次利息をグラフ表示
- 円・米ドル・ユーロ・豪ドルに対応
- 外貨を指定レートで円換算
- CSVバックアップ／復元
- スマホ内のlocalStorageに保存
- PWAとしてオフライン利用

## 使い方
### PCで簡単に試す
フォルダ内でローカルサーバーを起動してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

### iPhoneで使う
GitHub Pages、Netlify、Cloudflare Pagesなどにこのフォルダを公開し、
Safariで開いて「共有」→「ホーム画面に追加」を選びます。

## 利息計算
- 預入日は利息計算に含めません
- 満期日は利息計算に含めます
- 単利
- 365日または360日割
- 税率は各定期ごとに設定
- 外貨は登録した円換算レートで集計

## 注意
銀行ごとに端数処理、付利単位、起算日、税計算方法が異なる場合があります。
この初期版は管理・概算用です。
