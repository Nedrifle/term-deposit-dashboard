# 定期預金 利息ダッシュボード

## できること
- 複数の定期預金を登録
- 今日の合計利息を税引前・税引後で表示
- 預金ごとに現在の税引後累計利息を表示
- 運用中元本を金額比率と年利で示す利回り構成グラフを表示
- 外貨預金は累計利息の円換算額と元本の為替差損益を個別表示
- 今月の累計利息を表示
- 満期までの予定利息を表示
- 今後30日の日次利息をグラフ表示
- 余剰資金と期待金利から1日当たりの利息を算定
- 余剰資金の日次利息について税率20.315%控除後の金額も表示
- 円・米ドルに対応
- 米ドルの現在レートを手入力して円換算
- CSVバックアップ／復元
- スマホ内のlocalStorageに保存
- PWAとしてオフライン利用

## 使い方
### PCで簡単に試す
フォルダ内でローカルサーバーを起動してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

### iPhoneで使う
GitHub Pages、Netlify、Cloudflare Pagesなどにこのフォルダを公開し、
Safariで開いて「共有」→「ホーム画面に追加」を選びます。

## 利息計算
- 預入日は利息計算に含めません
- 満期日は利息計算に含めます
- 単利
- 365日または360日割
- 税率は各定期ごとに設定
- 外貨は登録した円換算レートで集計
- 余剰資金の日次利息は「余剰資金 × 期待年利 ÷ 100 ÷ 365」で算定
- 余剰資金の税引後日次利息は税率20.315%で概算

## 注意
銀行ごとに端数処理、付利単位、起算日、税計算方法が異なる場合があります。
この初期版は管理・概算用です。

## 複数の預金保有者を管理する
- 画面上部で保有者を追加し、個人または「全員合算」を選択します。概要、一覧、為替明細、グラフが切り替わります。
- 預金の登録・編集フォームで保有者を指定します。既存預金は「本人」に引き継がれます。
- 余剰資金・ヘッジ損益は個人画面で入力します。合算画面では余剰資金の金利を金額加重平均し、日次利息・ヘッジ損益を合算します。
- USDレートは選択中の保有者の運用中預金に反映します。全員合算では全員に反映します。
- CSVは常に全員の預金と保有者名を出力します。読込は全員の既存預金を置き換えます。旧CSVは本人の預金として読み込みます。余剰資金・ヘッジ損益はCSVに含まれません。
- 保有者の切り替えは表示の絞り込みで、ログインやアクセス制限ではありません。
