# 定期預金 利息ダッシュボード

## できること
- 複数の定期預金を登録
- 今日の合計利息を税引前・税引後で表示
- 預金ごとに現在の税引後累計利息を表示
- 運用中元本を金額比率と年利で示す利回り構成グラフを表示
- 外貨預金は累計利息の円換算額と元本の為替差損益を個別表示
- 今月の累計利息を表示
- 満期までの予定利息を表示
- 今後30日の日次利息をグラフ表示
- 余剰資金と期待金利から1日当たりの利息を算定
- 余剰資金の日次利息について税率20.315%控除後の金額も表示
- 円・米ドルに対応
- 米ドルの現在レートを手入力して円換算
- CSVバックアップ／復元
- スマホ内のlocalStorageに保存
- PWAとしてオフライン利用

## 使い方
### PCで簡単に試す
フォルダ内でローカルサーバーを起動してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

### iPhoneで使う
GitHub Pages、Netlify、Cloudflare Pagesなどにこのフォルダを公開し、
Safariで開いて「共有」→「ホーム画面に追加」を選びます。

## 利息計算
- 預入日は利息計算に含めます
- 満期日は利息計算に含めません（満期日当日から満期済みに分類）
- 単利
- 365日または360日割
- 税率は各定期ごとに設定
- 外貨利息は運用中・満期後ともに預入時レートで円換算し、円転時との差額を確定為替差損益に計上
- 余剰資金の日次利息は「余剰資金 × 期待年利 ÷ 100 ÷ 365」で算定
- 余剰資金の税引後日次利息は税率20.315%で概算

## 注意
銀行ごとに端数処理、付利単位、起算日、税計算方法が異なる場合があります。
この初期版は管理・概算用です。

## 複数の預金保有者を管理する
- 画面上部で保有者を追加し、個人または「全員合算」を選択します。概要、一覧、為替明細、グラフが切り替わります。
- 預金の登録・編集フォームで保有者を指定します。既存預金は「本人」に引き継がれます。
- 余剰資金・ヘッジ損益は個人画面で入力します。合算画面では余剰資金の金利を金額加重平均し、日次利息・ヘッジ損益を合算します。
- USDレートは選択中の保有者の運用中預金に反映します。全員合算では全員に反映します。
- CSVは常に全員の預金と保有者名を出力します。読込は全員の既存預金を置き換えます。旧CSVは本人の預金として読み込みます。余剰資金・ヘッジ損益はCSVに含まれません。
- 保有者の切り替えは表示の絞り込みで、ログインやアクセス制限ではありません。

## 月ごとの損益
「累計損益」の下に、選択年の1〜12月の税引後利息を実績（今日まで）・予測（明日以降）・合計に分けて表示します。選択中の保有者、または全員合算の預金を対象とします。預金の為替差損益とFX損益は利息の月別表には含めず、従来どおり年間累計グラフで集計します。外貨利息は年間グラフと同様、預入時レートで円換算します。

## FX損益の登録
- 「FX」タブで、2026年1月以降の実現損益を、行が年月・列がFX会社の表に入力できます。表示年を切り替えて登録します。
- FX会社は追加・名前変更でき、会社一覧は全保有者で共通です。いずれかの保有者・年に金額がある会社は削除できません。
- 金額は円単位で、負数・小数・桁区切りのカンマにも対応します。有効な数値を入力するとこの端末のlocalStorageに自動保存します。
- 未実現損益は現時点の全FX会社合計を上書き入力します。過去の値を累積する方式ではありません。
- 保有者別に登録し、全員合算では閲覧のみです。
- 概要の4項目表示は維持し、「ヘッジ・決済済み損益」はFX実現損益の全登録年月合計、「ヘッジ・未決済損益」は現在の未実現損益を参照します。表示年の切り替えで概要の合計は変わりません。
- 従来の実現損益は年月・会社が不明なので「年月未分類の引き継ぎ額」として合算します。月別表へ振り分けた分は引き継ぎ額から差し引いてください。従来の未実現損益は現在額として引き継ぎます。
- 預金のCSVバックアップにはFX損益・FX会社のデータは含まれません。

## 外貨利息と為替差損益の円換算
- 日次・累計・満期予定利息、年間グラフ、月別表の外貨利息は、満期後も預入時レートを使用します。現在レートの更新で利息の円換算額は変わりません。
- 満期後に円転レートを入力すると、税引後満期利息 ×（円転時レート − 預入時レート）を利息の確定為替差損益として計上します。元本の確定為替差損益と合わせ、概要の「預金・円転済み確定損益」に含めます。
- 利息受取時レートは既存データ・CSVとの互換性のため参考情報として保持し、計算には使用しません。
- 運用中の評価損益は従来どおり元本の評価差額を対象とし、利息の為替差額は円転時に確定計上します。

## 年間損益グラフの計上日
- 外貨預金の確定為替損益（元本＋税引後利息）は、満期済みで円転レートがある預金について満期日に計上します。実際の円転日を記録していないため、満期日を実現日とみなします。
- FXの会社別・月別実現損益は各登録月の月末日に計上します。未来の月の登録値はその月末以降の予測に反映します。
- 当年の計上日だけを累計するため、全登録年月・全預金を集計する概要カードとは対象期間が異なります。
- 運用中預金の評価損益、FX未実現損益、年月未分類のFX引き継ぎ額は、履歴・計上日がないため、従来どおり今日以降に現在額を加えます。予測期間の評価額は現在額のままとし、未到来の満期の確定為替損益は予測計上しません。
- グラフは日単位で描画し、満期日・月末日を間引きません。利息部分の計算方法と月別利息表は従来どおりです。

## 累計損益の年度フィルターと積み上げ表示
- 「累計損益」の年度フィルターは暦年（1月1日〜12月31日）で、グラフとその下の月別利息表に連動します。選択年は端末に保存します。登録済み預金・FXデータのある年、今年、翌年を選べます。
- 積み上げの種類は税引後利息、預金の確定為替損益、預金の評価損益、FX実現損益、FX未実現損益の5種類です。利益は正側、損失は負側に積み上げ、差し引き合計を黒線で表示します。予測は淡色・破線です。
- タップ・マウス操作で選択日の種類別内訳と合計を確認できます。
- 過去年は年末の実績、未来年は年末予測を表示します。評価損益と年月未分類のFX引き継ぎ額は履歴がないため、今年の今日以降にのみ反映し、過去年・未来年に現在額を持ち込みません。確定損益は選択年の満期日、FX実現損益は選択年の月末日で計上します。
